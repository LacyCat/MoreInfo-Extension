# MoreInfo - 더 많은 정보, 더 나은 OJ
MoreInfo는 솔브닥(solved.ac)의 최신 v4 API를 사용해 더 많은 정보를 보여줍니다. \
현재는 BOJ만 지원하지만, 추후 더 많은 OJ에 대해 지원할 예정입니다. 
## 설치 및 사용
1. 릴리즈에서 브라우저에 맞는 ZIP을 다운받습니다. 
2. ZIP을 압축 해제하고, 각 브라우저에 주소를 쳐서 익스텐션 창에 들어갑니다. 
- (크롬의 경우: chrome://extensions) 
- (파이어 폭스의 경우: about:debugging) 
3. 크롬은 오른쪽 위의 개발자 모드 스위치를 ON으로 전환하고, 압축해제된 확장 프로그램 로드를 눌러 폴더를 엽니다.
4. 파이어 폭스는 about:debugging으로 가서 좌측 메뉴 -> 이 파이어폭스 선택 후 임시 부가 기능 로드를 눌러 manifest.json을 선택합니다. \
 \
**파이어 폭스의 경우, 브라우저를 완전히 재시작하면 익스텐션이 해제됩니다.** \
추후 심사 과정을 거쳐 정식 파일로 배포하도록 하겠습니다.
## 기능
- 문제 옆에 예상 레이팅 증가량 표시 및 예상 티어 변화 표시. 
- 문제집의 예상 레이팅 증가량 표시 (예정됨)
- 문제의 각 태그별 레이팅 증가량 표시 (예정됨)
## 표시가 안 떠요!
표시가 안 뜨는 경우는 여러가지가 있습니다.
- 로그인이 안 됨
- API를 너무 자주 호출해 레이트 리밋에 걸림
- API를 너무 자주 호출해 솔브닥 API 예산을 다 씀
- 문제가 언레이티드임 \
 \
API를 자주 호출해 일어나는 문제는 몇 초 후 시도하면 고쳐질 수 있습니다. \
만약 버그가 존재하거나, 표시가 보이지 않는다면 이슈를 게재하시기 바랍니다. \

알려진 버그: 
- 전체 문제 혹은 문제 탭에서 화면을 줄였을 때 제목과 표시가 겹쳐지는 이슈

### 고의적으로 하드코딩된 API 주소로 과도하게 호출하거나 취약점 사용을 시도할 시 영구 블락될 수 있습니다.
